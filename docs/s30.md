# S30-V1B 单路计量插座

0.2.11 起支持 ORVIBO S30-V1B（BL2028N / BK7231N）刷入 [IoTCloud 社区固件](https://phicomm-io.github.io/guides/s30-guide.html)后的接入。

## 添加与控制

点击“添加设备”扫描，或选择“S30-V1B 单路插座”并填写设备内网地址。设备设置网页密码时填写对应密码；管理端自动使用 MessagePack 与 HTTP Basic。支持识别 `_openiot._udp` 的 mDNS 广播，再通过设备 HTTP 接口核验型号和 MAC；自动扫描、IP 变化后的连接恢复沿用现有流程。

卡片显示一路插口状态及功率、累计用电、电压和电流。控制弹窗支持开关、指示灯、童锁与插口名称编辑。名称修改写入设备，设备网页修改后的名称也会随状态采集更新。

MQTT 使用 `phicomm/v2/<scope>/s30-v1b/<mac>/` 主题，支持 OpenIoT / TMCP v2 的 schema 2 自动发现与 MessagePack 命令。设备需填写当前服务设置中的 Broker 和账号；HTTP 与 MQTT 按同一型号和 MAC 合并，不重复建设历史。

## 计量和历史

电压、电流、功率来自完整状态的 `metering` 字段，分别检查 `valid_fields`。无效读数显示“—”，历史和 CSV 留空；有效的 0 值正常保留。累计 `energy_kwh` 按度显示，沿用统一 / 峰谷电价估算，不追溯未知用电。

历史按现有规则每分钟记录一次、保留最近 30 天。可选择功率、用电量、预估花费、电压或电流，作为历史指标和卡片默认曲线；导出全部 CSV 新增电压、电流列。

本次已用固件 `1.0.0-29a90f` 实机验证网段扫描、身份识别、状态读取、历史写入与 CSV；控制、密码验证、双向名称同步和 MQTT 使用模拟设备测试。测试过程中没有修改实机设置或切换真实负载。

开发者可通过 `PHICOMM_TEST_S30_URL` 指定设备地址，运行 `go test -run '^TestS30LiveReadOnly$' -v .`。另设 `PHICOMM_TEST_S30_CIDR` 可验证指定内网网段的实际扫描。检查只读取设备，管理端数据写入临时数据库。
