# 安装 IoT 设备管理 0.2.10（Go + React）

适用于 fnOS 1.2.0 及以上。ARM 包面向 ARM64 / AArch64 NAS；x86 包面向 x86-64 NAS。程序已编译并内置网页、SQLite、MQTT 服务，无需安装 Node.js、Go、数据库或 Docker。

1. 在飞牛应用中心选择手动安装，ARM64 NAS 上传 `phicomm-manager-0.2.10-arm.fpk`，x86-64 NAS 上传 `phicomm-manager-0.2.10-x86.fpk`。
2. 安装完成后使用飞牛 NAS 管理员账号，从桌面打开“IoT 设备管理”。无需应用管理密码。
3. 点击列表 / 空间视图下方的“添加设备”，自动扫描设备；需要重试时点击“扫描设备”。也可填写设备内网地址。
4. “设置 → 设备连接”修改设备名称、空间和连接方式；“设置 → 服务设置”配置内置 MQTT 或外部 Broker。
5. “设置 → 电价设置”填写统一电价或峰谷电价，TC1 控制区显示累计用电与小字预估消费；空间卡片显示实时功率和累计用电。

“设置 → 外观”可选择浅色、深色或跟随系统主题，修改后即时生效并记住当前设备的选择。

本工具由 [情深深雨蒙蒙（yueqihe）](https://github.com/yueqihe) 维护，基于 [phicomm-io 斐讯设备社区项目](https://github.com/phicomm-io/)的设备协议和固件生态制作。[源码仓库](https://github.com/yueqihe/phicomm-fnos-manager)提供完整 Go + React 管理端和构建脚本，设备资料见[社区文档](https://phicomm-io.github.io/)。

可借助 fnOS 的远程访问，在外网登录飞牛并从桌面打开本工具，远程查看和控制设备。先确保 NAS 能通过局域网或 MQTT 连接设备，再在 fnOS 中配置远程访问与应用入口。设备无需单独映射网页或 MQTT 端口到公网。

从 0.1.x 或 0.2.0–0.2.9 升级会继续读取原 SQLite 数据库与 `secrets.key`，保留设备、连接密码、空间、历史数据和电费记录。请通过应用中心升级，保留应用数据。原先的 Node.js 22 应用已经不再是本包的依赖。

列表快速控制和空间控制弹窗均可点击插口名称修改，保存后直接写入设备并读取确认。设备原网页修改名称后，管理端会随自动采集更新；编辑中的草稿保留，失败时可重试或取消。

设备状态自动更新，无需点击刷新。局域网设备默认每 15 秒采集，MQTT 随设备上报更新；页面默认每 5 秒同步，切回前台或网络恢复时立即同步。“设置 → 刷新设置”可分别填写页面刷新间隔（2–300 秒）和局域网采集间隔（5–60 秒），保存后立即生效并保存在 NAS；其他浏览器随下次同步应用新配置，重启后保留。历史仍按分钟记录。

打开管理页面后自动扫描一次，页面保持打开时每分钟扫描一次。新发现且尚未登记的设备会显示“添加 / 暂不添加”提示，点击添加后预填型号和地址，由用户确认接入；选择暂不添加后，本次打开期间不重复提醒同一设备。多个页面共用正在进行或最近一分钟的自动扫描，关闭所有页面后停止新设备扫描，异常断开时也会自动结束。此流程与离线设备的地址恢复独立，不会自动添加未知设备。

局域网地址变化时，连续 3 次采集失败会自动重新发现设备；每轮恢复扫描至少间隔 2 分钟，并重新读取 NAS 当前网段，适用于 DHCP 换 IP 或更换路由后 NAS 与设备已连接到新网络的情况。核对型号和 MAC 后只更新原设备地址，保留名称、空间、曲线设置、历史和累计电费；手动扫描也会恢复已登记的设备。同一设备重复添加会合并连接并保留原配置。

设备设有网页密码、使用未通过 mDNS 广播的自定义端口，或处于默认扫描范围之外时，可在“设置 → 设备连接”直接修改原设备的内网地址，或手动指定网段扫描，无需删除设备。扫描不会向未知地址尝试已保存的密码。设备必须先接入 NAS 可访问的网络，管理端不能替设备更换 Wi-Fi；MQTT 设备更换 Broker 地址时仍需更新设备端配置。历史仍遵循最近 30 天保留规则，断网期间不补造读数；此前已删除的设备配置和电费累计无法凭空恢复。

默认打开空间视图，四种设备卡片均显示最近 24 小时的小曲线。点击卡片或控制区的曲线，或顶部历史图标，可进入历史弹窗；“活动记录”继续查看操作结果。历史数据每分钟保存一份，保留最近 30 天，支持 24 小时 / 7 天 / 30 天切换、轻点曲线查看读数和导出当前汇总数据为 CSV。TC1 可查看功率、用电与预估花费，M1 / DAIKIN 可查看空气指标，A1 可查看风机输出和滤芯剩余。

历史弹窗的“数据指标”右侧提供“卡片显示曲线”下拉框，单独指定每台设备卡片和控制弹窗的近 24 小时指标，选择后自动保存；左侧“数据指标”只改变当前查看的数据。“设置 → 设备连接”也可以修改同一配置。默认是 TC1 功率、M1 / DAIKIN 的 PM2.5 和 A1 风机输出；也可选择设备支持的其他空气指标、用电量、花费或滤芯。保存后刷新、换浏览器和重启应用均保留；点击曲线直接打开对应指标的历史，没有有效数据时等待新记录。用电量和花费显示区间合计柱形，其他指标显示曲线。

“设置 → 数据导出 → 导出全部 CSV”可下载所有设备已保存的完整历史读数，一条记录一行，不按图表粒度汇总。文件包含设备 ID、名称、型号、MAC、空间、北京时间和各项原始指标，未上报的指标留空；TC1 导出累计用电和累计预估花费。已移除设备仍保留的历史也会导出，以设备 ID 识别。CSV 使用 UTF-8 编码并附带 BOM，便于在 Excel 中显示中文。

实时读数按状态变色：TC1 功耗从 1000 W 起为橙色、2000 W 起为红色；M1 / DAIKIN 的 PM2.5 在 35 μg/m³ 及以下为绿色、36–75 为橙色、更高为红色，并显示对应分级；A1 实际风机输出从 60% 起为橙色、85% 起为红色。列表、空间卡片和控制弹窗使用相同规则，离线或无效采样不显示状态色。

历史从启用后开始累计，离线或无效读数不回填。用电和花费按所选时段内保存的读数差额统计，计量归零后重新起算，花费保留当时的计费结果；未设置电价时不生成费用记录。历史存于同一 SQLite，重启后保留，备份数据目录时一并备份。

桌面入口仍通过飞牛统一网关 `/app/phicomm-manager/`，后台使用本地 Unix Socket，仅信任网关传入的管理员身份，不开放额外 HTTP 管理端口。内置 MQTT 编入同一可执行文件，启用后监听配置的 TCP 端口，设备仍需填写对应的 MQTT 账号和密码。

仅支持兼容社区固件的 TC1 / M1 / A1 / DAIKIN。兼容 TC1 `0.9.6-ed4474` 缺少 `info.get` 和状态型号的情况，从同一设备的能力接口补全型号并检查 MAC；控制命令不跨连接重放。LAN 与 MQTT 按型号和 MAC 合并。

DAIKIN 接入面向 [IoTCloud 社区固件的 BRY88AX151K](https://phicomm-io.github.io/guides/daikin-guide.html)，与现有设备共用局域网扫描和 TMCP v2 MQTT。可显示 PM2.5、PM10、CO₂、温湿度、TVOC（ppb）及可选甲醛，并控制空气质量指示灯。各传感器独立判断有效性，CO₂ 预热不影响其他读数；没有甲醛模块时隐藏该项，已检测模块失效时显示空值。原厂固件和 ESPHome 不使用此协议。

添加弹窗通过同一个“扫描设备”入口结合 mDNS 与局域网探测，并按设备身份合并结果。默认检查所有可用局域网接口，并排除容器网桥等虚拟接口；每个接口扫描所在 /24 或实际更小子网。系统限制接口枚举时，会尝试通过路由表识别网络，无需 root 或额外依赖。

网卡和扫描网段位于折叠的“高级选项”。接口仍读取不到时，网络接口保留“自动选择”，填写 `192.168.1.0/24` 等内网网段后即可扫描，也支持填写单个 IPv4 地址。设备位于其他可路由的内网网段时，也可用此方式指定；每个网段最多 1024 个地址（/22 至 /32）。明确选择某张网卡时，网段须位于该接口内。

mDNS 使用 UDP 5353，无需 Avahi；即使广播不可用，网段探测仍会执行。扫描检查 TCP 80 并通过固件接口核验身份，支持进度和停止。自定义网页端口可手动添加。设备有网页密码时，先选地址，再填写密码验证接入。

1 kWh = 1 度。电费从启用后的首次有效读数开始记录，不追溯历史用电。峰谷时段按北京时间每日重复，支持跨午夜；两次读数间的电量按时间比例估算，离线间隔同样分摊。改价保留已记录费用，下一次新读数重新起算；电量归零时重建起点。此费用仅供参考。

数据目录：`/var/apps/phicomm-manager/var/data/`。备份前停止应用，再完整复制目录，保留 SQLite 及其辅助文件和 `secrets.key`。日志：`/var/apps/phicomm-manager/var/app.log`。应用以专用包用户运行。

验证覆盖 Go REST、React 页面、四种设备控制与身份校验、旧版 TC1、MQTT 内置 / 外部接入及权限、统一扫描和取消、mDNS 报文、旧版数据与加密凭据兼容、电费与手机界面。两个包分别校验 ARM64 / x86-64 ELF 架构、静态链接和可执行权限。

空气检测仪空间卡片在 PM2.5 下方显示温度、湿度、甲醛等实时指标；大金另显示 PM10、CO₂、TVOC，甲醛按实际模块显示。卡片与控制区共享有效性和颜色规则，手机按卡片宽度调整列数。

TC1 空间卡片在功耗下方逐一显示六路插口的编号、自定义名称和开关状态。桌面三列两行，窄屏两列三行；开启为绿色、关闭为灰色，设备离线时显示离线。点击状态区域打开原有控制弹窗，名称和状态随设备自动同步。
